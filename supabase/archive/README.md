# Archive: history only. Do not run anything in this folder.

These are the old, scattered database scripts from before everything was merged into one file.
They are kept so you can see how the database got here. Everything in them is now in
`../schema.sql`, which is the only script you run (plus `../make_admin.sql` once).

- `schema-original-b2b.sql`: the original butchery / supplier / carrier database.
- `2026*.sql`: the step-by-step migrations that came after it.
